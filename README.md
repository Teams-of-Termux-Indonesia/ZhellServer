## Setup
Run the following command in Termux.

### Install curl

```bash
pkg install curl -y
```

### Run setup script via curl

```bash
curl -fsSL https://raw.githubusercontent.com/Teams-of-Termux-Indonesia/ZhellServer/main/setup.sh | bash
```
